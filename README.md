# TECHNO-METAL Production History

Public, static historical report snapshot. Not live Server data.

- Report-date coverage: 2026-08-20 through 2026-10-28 (68 dates)
- Latest source record: 2026-10-28 14:50:23 Asia/Bangkok
- Requested upper limit: 15:00; the final 9 minutes 37 seconds are not available in this source.
- 1,359 canonical robot/date/shift records, 698,412 pieces; October 28 DAY: 4,031 pieces.
- Missing complete dates: September 17 and September 24. Other missing robot/shift records are not assumed to be zero.
- 107 duplicate STANDARD/EXTENDED views removed using the source Server selection policy.
- 1,339 full records, 19 partial backfill records, 1 recovered/unallocated record. AVG is suppressed for incomplete/recovered selections or missing time.
- AVG SEC/PC = sum recorded robot work seconds / sum pieces; AVG PCS/hr = 3600 * sum pieces / sum recorded robot work seconds. These are weighted robot-work-time rates, not plant wall-clock output.
- Part filters use allocated part quantities/time only. Part totals exclude 58 transition pieces and one unallocated recovered piece.
- Report dates preserve Server ownership, including overnight shifts. No date reassignment by midnight.

Only approved production-report fields and the company logo are included. No raw databases, controller files, programs, credentials, private network addresses, or personnel data. Source package content was validated; this site does not assert that the import was applied to a running Server.

Part analysis offers 25 known identities plus a separate unknown group. J/K, C/T and S/C profiles are not merged across the same part number. The all-history Part action clears date, robot, shift and profile restrictions while preserving the chosen Part. Report first/last times remain robot/shift-level, not selected-part timing.
