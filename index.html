    ค่าเฉลี่ย Analysis ใช้ผลรวม total_sec ของ Run ÷ PCS และ 3,600 × PCS ÷ total_sec ไม่ใช้การเฉลี่ยค่า AVG รายแถว และไม่ใช้สถานะความครบถ้วนจากรายงานกะคนละแหล่ง

    การคำนวณค่าเฉลี่ย

    คำนวณจากผลรวมเวลาและจำนวนผลิตที่จับคู่กัน ไม่เฉลี่ยค่า AVG รายแถว รายการที่เวลาไม่ครบแสดง — ส่วน AVG รวมประวัติรายงานกะใช้เฉพาะรายการที่มีจำนวนผลิตมากกว่า 0 และเวลาครบ พร้อมแสดงสัดส่วนข้อมูลที่ใช้คำนวณ
